# 📚 Project Documentation & Technical Reports

This directory serves as the theoretical and architectural foundation for the **Solar-Powered EV Charging Station** project. It bridges the gap between mathematical state-space modeling, software simulation, and physical hardware implementation.

## 📂 Contents

*   **`Graduation_Project_Book.pdf`** *(Update with your actual file name)*: The comprehensive thesis document. This report details:
    *   Mathematical modeling and I-V/P-V characteristics of the solar array.
    *   Component sizing, inductor/capacitor selection, and state-space averaging for the DC-DC converters (Interleaved Boost, Two-Quadrant Chopper, and Buck).
    *   Closed-loop control system design and PI controller tuning strategies.
*   **`Final_Presentation.pdf`** *(Update with your actual file name)*: The presentation slides used during the final graduation defense, summarizing the problem statement, system architecture, MPPT algorithms, and hardware validation results.

## 🎯 Purpose
These documents are provided to offer deep engineering context. Anyone reviewing the MATLAB/Simulink models or the Altium PCB designs in the other directories can reference these reports to understand the design choices, efficiency calculations, and control logic derivations.
